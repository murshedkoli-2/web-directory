# 🚀 Web Directory — Modern Digital Portal & Curated Web Directory

A modern, high-speed digital web directory and domain portal built with **Next.js**, **Prisma ORM**, **Neon PostgreSQL**, and **Tailwind CSS**. Enables users to discover, bookmark, categorize, and submit verified digital services and online resources.

---

## 🌟 Key Features

- **🔍 Multi-Category Directory**: Browse indexed tools, services, and websites filtered by domain, tags, and ratings.
- **🛡️ Verification & Submission System**: User submissions pipeline with administrative approval and security validation.
- **⚡ Ultra-Fast Search**: Instant client and server search across indexed resources.
- **🎨 Modern Glassmorphic UI**: Accessible components built with Radix UI primitives and Tailwind CSS.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15, React 19
- **Database**: PostgreSQL (Neon Serverless) with Prisma ORM
- **UI & Styling**: Radix UI (Dialog, Dropdown, Select, Tabs, Tooltip), Tailwind CSS
- **Icons**: Lucide React

---

## 🚀 Quickstart

```bash
git clone https://github.com/murshedkoli-2/web-directory.git
cd web-directory
npm install
npx prisma db push
npm run dev
```
